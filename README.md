# Simple Todo App

Project Description

The Simple Todo App is an interactive task management application that allows users to organize and manage their daily tasks. Users can create new tasks, assign optional due dates, mark tasks as completed, and delete tasks they no longer need.

The application uses Object-Oriented Programming (OOP) principles to organize JavaScript code into reusable classes, improving readability, maintainability, and scalability.

## Functionality

Add new tasks using a popup form.

Assign optional due dates to tasks.

Mark tasks as completed or incomplete using checkboxes.

Delete unwanted tasks.

Validate form inputs and display error messages.

Disable the submit button when form inputs are invalid.

Automatically reset the form after successfully adding a task.

Generate unique IDs for newly created tasks.

## How to Use

Click the + Add Todo button.

Enter the name of your task.

Select an optional due date.

Click Create to add the task to the list.

Select the checkbox to mark the task as completed.

Click the delete button to remove a task.
